## Objective

Rework Codex Cove around one safe, fast path while preserving its notch
resident, residents, themes, and local-only privacy model:

```text
Collapsed glance -> Attention-first queue -> Focused action -> Confirm or open source
```

Ship the complete P0, P1, and P2 scope from the UX audit. Keep SwiftPM as the
production build source, keep the public Codex interfaces unchanged, and keep
the Cove event envelope at schema v1. The private remote relay control layer
may add an internal delivery acknowledgment without representing downstream
Codex acceptance.

## Locked Decisions

- Release includes P0 decision safety and accessibility, P1 queue and focused
  action work, and P2 Settings polish.
- Positive approval choices use select-then-confirm. `Allow once` and `Allow
  for this task` stage a choice; a separate confirmation sends it. Decline and
  Cancel remain one-click actions.
- Overlay has three transient presentation states: collapsed, 400-point queue,
  and 520-point focused action surface. All remain centered on the same
  screen-top anchor.
- Escape moves focused -> queue -> collapsed.
- Unsent choices and answers make a focused surface dirty. Dirty surfaces do
  not auto-collapse; Escape offers Keep Editing or Discard.
- Full Xcode installation is an implementation prerequisite. Add an XCUITest
  project and shared scheme without replacing the SwiftPM production build.
- App is unreleased. Change defaults and stored model directly; do not build a
  migration or compatibility migration.
- Owner validation is one scripted pass after automated and manual matrices,
  not a moderated user study.

- [x] Expand delivery state to staged, sending, succeeded, and failed.

## Public Interfaces and Data Boundaries

- New app-layer types: `CoveOverlayPresentation`, `CoveFocusTarget`,
  `CoveActionDraft`, and expanded decision-delivery status.
- `CoveEvent` gains local optional turn identity and wire-kind metadata.
- `CoveOriginScope` supplies composite non-content identity: source for local
  CLI/Desktop, and source plus selected host ID for remote CLI.
- Panel sizing and controller update APIs accept presentation mode alongside
  application state.
- The Cove event envelope remains schema v1. Its current presentation model
  cannot show two cross-origin cards that collide on the same raw upstream ID;
  the incoming collision is hidden fail-closed pending a future composite card
  identity.
- Public Codex interfaces and local CLI decision frames remain unchanged. The
  private remote relay control layer adds correlated `decisionAck` frames; they
  acknowledge only the remote helper's socket write, never downstream Codex.
- Opaque Desktop thread/session IDs are persisted only in Cove's private SQLite
  metadata for hydration and exact Open. Prompt/response content is not
  persisted, and neither IDs nor content are written to repository evidence or
  the root `SOURCE_CANDIDATE.receipt`.
- Drafts, focus targets, delivery UI state, and UI-test fixtures are transient;
  do not persist them.

- Resident character selection
