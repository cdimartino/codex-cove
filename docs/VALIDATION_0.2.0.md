Local production decision delivery has no receiver ACK. A local `succeeded`
state records completion of the validated private-socket frame write. Remote
delivery adds a correlated internal relay `decisionAck`: `delivered` is emitted
only after the remote helper completes the private-socket write, while failure,
or timeout leaves the route available for retry. A disconnect fails all pending
sends and invalidates that relay generation's routes. Per-host relay writes are
serialized. Neither the local write nor the remote internal ACK is a downstream
Codex acknowledgment. Only the injected fixture sender exposes a deterministic
invocation count to XCUITest.

## Implemented post-baseline hardening

- Task identity is composite: source scopes local CLI versus Desktop, and a
  remote origin additionally requires its selected host ID. Reduction,
  direct-request matching, activity aggregation, persisted metadata,
  notification resolution, and exact Open all use that origin and fail closed
  when it is missing or ambiguous.
- Schema v1 still keys presented cards by raw upstream identifiers. If two
  origins collide on snapshot/session/launch ID, Cove deliberately hides the
  incoming colliding card instead of replacing or routing through the other
  origin. Showing both simultaneously requires a future schema/presentation
  identity change.
- The VS Code/Cursor extension provides one live focus server per editor
  window and a fresh opaque launch ID per Cove-created routed terminal. It
  supports registration-before-launch, launch-before-registration, and
  sequential sessions in the same terminal. Legacy sensitive global state is
  removed; only a validated opaque extension session ID persists. A
  content-free per-window accessibility anchor allows Cove to raise and verify
  the exact native editor window between two confirmed terminal-focus phases;
  missing, duplicate, stale, or inaccessible anchors fail closed.
- Startup attention arriving before Notification Center is ready is held in a
  bounded 128-entry memory-only FIFO. On service readiness it drains only
  entries still current under the latest attention, privacy, and suppression
  state. Notification clicks require an exact composite origin and unique
  session/launch match; ambiguity does not fall back to the current task.
- The collapsed island exposes a real `Open task queue` Button with stable AX
  identifier/value/hint. Privacy controls have stable AX identifiers, and
  privacy redaction removes live project/task suggestions from Settings and
  its accessibility tree.
- Doctor now validates the private manifest and owned paths, managed hashes,
  current app identity/version, a freshly recomputed app-tree hash against the
  manifest, exact hook handler ownership, recorded editor targets, socket,
  schemas, and remote artifact completeness.
- Installer/uninstaller transactions preserve a valid existing configuration,
  serialize writers under a persistent lock, bind every staged/replaced path
  to its current-user filesystem identity, fail closed on concurrent identity
  changes, and preserve recovery material when commit/rollback cleanup cannot
  finish. Recorded editor cleanup targets are verified rather than silently
  skipped.
