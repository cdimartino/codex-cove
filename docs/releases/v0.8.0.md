# Codex Cove 0.8.0
<!-- release-tag: v0.8.0 -->

Codex Cove 0.8.0 makes saved Workspace artifacts editable and globally
orderable, adds privacy-bounded favicons for saved web links, and lets Workspace
target newly discovered top-level tasks and nested agents exactly. These notes
describe the source candidate bound to `v0.8.0`; signing, notarization,
publication, and Homebrew availability remain prospective until the protected
release workflow finishes.

Source tag: `v0.8.0`

## Highlights

- Saved artifact labels can be edited inline. Return or focus loss commits a
  trimmed valid label, Escape restores the saved value, and invalid labels are
  never persisted.
- Parent and descendant artifacts share one durable Workspace order without
  changing ownership. Drag and accessible **Move Earlier**/**Move Later**
  controls support named Undo and Redo across agent boundaries.
- Saved public HTTP and HTTPS links can display a small favicon in the
  inspector and card badges. Local files, suggestions, failed requests, and
  privacy-redacted views keep the existing generic symbols.
- Workspace can select an exact nested agent while keeping its owning task
  highlighted. The inspector, composer, confirmation, refresh state, and Open
  action follow that selected identity.
- Newly discovered top-level tasks and structured subagents now resolve their
  authoritative ancestry, hydrate current turn state, and revalidate the exact
  target immediately before Start or Steer. Conflicts and stale routes remain
  fail-closed.
- Exact child navigation failures are visible on the selected agent. When a
  verified same-origin ancestor has a location, Cove offers a separately
  labeled **Open Parent Location** action instead of silently substituting it.

## Installation and compatibility

Codex Cove 0.8.0 is intended for Apple Silicon Macs running macOS 14 or newer.
Remote helpers support Apple Silicon and Intel macOS plus arm64 and x86_64
Linux-musl hosts. Codex CLI 0.147.0 or newer remains required for Workspace
thread discovery and control.

Workspace storage migrates version 1 and 2 artifact arrays to the version 3
global order deterministically. Older Cove versions deliberately refuse the
newer Workspace file rather than discarding interleaved ordering, so install
0.8.0 or newer before reopening a migrated Workspace.

The release retains the `local.chris.codexcove` bundle identity and upgrades an
existing Homebrew installation in place while preserving settings, custom
themes, content-free session metadata, and saved Workspace content. After the
immutable release and generated Cask handoff are published and merged, update
with:

```sh
brew update
brew upgrade --cask cdimartino/codex-cove/codex-cove
```

The native `codex` command remains untouched. `codex-cove launch` remains the
preferred path for a continuously broker-routed CLI session.

## Security and privacy

Displaying a confirmed saved public web link can contact that link's host at
`https://<host>/favicon.ico`. Cove strips paths, queries, fragments,
credentials, and non-HTTPS transport; rejects local, private-name, and IP
hosts; refuses redirects; and uses an ephemeral five-second request with no
cookie or credential stores and a 256 KiB transfer cap. Images are decoded as
bounded 32-pixel thumbnails and cached only in process memory.

Cove still has no telemetry, favicon proxy, connector credentials, or hosted
service. Unsaved suggestions never trigger favicon traffic, and privacy
redaction prevents both rendering and fetching. Composer text and submitted
prompts remain memory-only.

Agent control follows at most 32 non-cyclic ancestors and accepts only a
confident local CLI or Codex Desktop root. Parent conflicts, cross-origin
chains, unsupported reviewer or guardian sources, missing ancestors, stale
turns, and pending requests remain rejected. Cove never retries an uncertain
prompt automatically.

The protected distribution workflow will fail closed unless the reviewed tag
matches protected `main`, candidate evidence and tests pass, Developer ID
signing succeeds, Apple notarization and Gatekeeper checks succeed, and every
downloadable asset is covered by `SHA256SUMS`.

## Known boundaries

- Favicon discovery intentionally requests only `/favicon.ico`; Cove does not
  parse site HTML or manifests, follow redirects, or authenticate, so some
  sites continue to show the generic link symbol.
- Start and Steer remain unavailable when Cove cannot prove the exact source
  chain, route, pending-request state, and active turn on the delivery
  connection. Open the selected task in Codex when verification fails.
- A child agent may not have its own openable location. **Open Parent
  Location** is an explicit fallback and never marks the child as opened or
  read.
- Homebrew availability follows a separate generated-Cask pull request; an
  immutable GitHub release alone does not update the tap's default branch.
