# Codex Cove 0.7.0
<!-- release-tag: v0.7.0 -->

Codex Cove 0.7.0 makes Workspace the primary task surface and adds durable,
parent-owned artifact context for active Codex work. These notes describe the
source candidate bound to `v0.7.0`; signing, notarization, publication, and
Homebrew availability remain prospective until the protected release workflow
finishes.

Source tag: `v0.7.0`

## Highlights

- Deliberate launch, Dock reopen, notifications, and queue-row selection now
  bring Workspace forward. The island remains the compact ambient companion.
- Workspace keeps observed tasks until you archive them. When a task is no
  longer currently observed, Cove labels it Retained instead of guessing its
  live state.
- A parent task can collect web links, local files, and folders as artifacts.
  Agent output can suggest explicit references, but Cove never saves or opens
  one until you confirm it.
- Artifact opening is centralized and rejects remote file URLs, credentials,
  executable or package targets, special files, and missing local documents.
- Native coverage verifies Workspace-first launch, queue routing, retained
  cards, artifact controls, safe opening feedback, and privacy-safe
  Accessibility rendering.

## Installation and compatibility

Codex Cove 0.7.0 is intended for Apple Silicon Macs running macOS 14 or newer.
Remote helpers support Apple Silicon and Intel macOS plus arm64 and x86_64
Linux-musl hosts. Codex CLI 0.147.0 or newer remains required for Workspace
thread discovery and control.

The release retains the `local.chris.codexcove` bundle identity and upgrades an
existing Homebrew installation in place while preserving settings, custom
themes, content-free session metadata, and explicitly saved Workspace content.
After the immutable release and generated Cask handoff are published and
merged, update with:

```sh
brew update
brew upgrade --cask cdimartino/codex-cove/codex-cove
```

The native `codex` command remains untouched. `codex-cove launch` remains the
explicit path for a broker-routed CLI session.

## Security and privacy

Workspace artifacts are local user-authored references stored in Cove's
mode-`0600` Workspace file. Cove stores no connector credentials and does not
scan repositories, private transcripts, prompts, templates, or Codex session
storage for suggestions.

Unsaved composer text, submitted prompts, upstream titles, assistant output,
approvals, questions, commands, diffs, and transcripts remain memory-only.
Privacy redaction removes artifact labels, paths, suggestions, and controls
from rendering, Accessibility, and search matching.

The protected distribution workflow will fail closed unless the reviewed tag
matches protected `main`, candidate evidence and tests pass, Developer ID
signing succeeds, Apple notarization and Gatekeeper checks succeed, and every
downloadable asset is covered by `SHA256SUMS`.

accepted by Gatekeeper before publication. The Homebrew Cask is staged only
after the workflow re-downloads and verifies the immutable release bytes.

## Known boundaries

- The graphical app remains Apple Silicon only; Intel macOS support applies to
  the optional remote helper, not the app bundle.
- Artifacts are references, not imported content or synchronized connector
  records. Missing local targets remain visible but cannot be opened.
- Artifact suggestions use only bounded current assistant output and require
  explicit confirmation before attachment.
- Homebrew availability follows the separate generated-Cask pull request; an
  immutable GitHub release alone does not update the tap's default branch.
