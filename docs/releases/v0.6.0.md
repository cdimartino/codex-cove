# Codex Cove 0.6.0
<!-- release-tag: v0.6.0 -->

Codex Cove 0.6.0 adds a full-window Workspace for supervising many Codex tasks,
organizing them in a responsive Grid or custom-column Board, and interacting
with exact originating tasks from one native macOS app. It also adds maintained
Workspace and Settings references plus inline help throughout the app. These
notes describe the source candidate bound to `v0.6.0`; signing, notarization,
publication, and Homebrew availability remain prospective until the protected
release workflow finishes.

Source tag: `v0.6.0`

## Highlights

- A reusable 1,200 by 800 Workspace window shares the live Cove store and
  switches Cove into a normal Dock and App-Switcher app while open. Closing it
  restores menu-bar accessory behavior without interrupting a Codex task.
- Grid provides manual drag ordering plus Attention, Recent Activity, Name, and
  Source sorts. Board provides Inbox, Doing, Review, and Blocked columns with
  user-managed columns and Cove-only workflow placement.
- Cards expose origin-safe status, activity, unread and pin state, tags, links,
  and descendant attention. A resizable inspector shows the recursive subagent
  hierarchy, memory-only latest output, approvals and questions, reminders,
  archive controls, metadata, and a prompt composer.
- Desktop reconciliation uses the public loaded-thread and read interfaces.
  Validated idle targets can start a turn, while active targets can steer the
  exact current turn. Routed local and remote sessions use correlated bounded
  control frames; unsupported or stale routes fail closed and offer exact Open
  in Codex instead of guessing.
- A searchable prompt library supports favorites, recent use, manual ordering,
  and explicit save. Choosing a template copies it into a memory-only composer;
  submitted prompts are never retried automatically or persisted by Cove.
- Composite task identity now includes source and remote-host scope throughout
  state, routing, metadata, hierarchy, queue identity, and persistence. Legacy
  metadata applies only when it resolves to one unambiguous origin.
- Full Workspace and Settings guides are linked from the native Help menu,
  menu-bar menu, Workspace toolbar, and every Settings pane. Non-obvious native
  controls provide hover help and accessible help labels.
- Open-in-Codex failures now remain visibly actionable instead of marking a task
  read, custom themes persist when Settings closes, and Privacy Off no longer
  retains an earlier automatic redaction state.

## Installation and compatibility

Codex Cove 0.6.0 is intended for Apple Silicon Macs running macOS 14 or newer.
Remote helpers support Apple Silicon and Intel macOS plus arm64 and x86_64
Linux-musl hosts. Codex CLI 0.147.0 or newer is required for the public loaded
thread, read, start, steer, and authoritative parent-thread contracts used by
Workspace.

The release retains the `local.chris.codexcove` bundle identity and upgrades an
existing Homebrew installation in place while preserving settings, custom
themes, content-free session metadata, and explicitly saved Workspace content.
After the immutable release and generated Cask handoff are published and
merged, update with:

```sh
brew update
brew upgrade --cask cdimartino/codex-cove/codex-cove
```

The native `codex` command remains untouched. `codex-cove launch` remains the
explicit path for a broker-routed CLI session.

## Security and privacy

Workspace introduces a deliberate local persistence exception for content the
user explicitly authors and saves: aliases, tags, validated HTTP or HTTPS
links, Grid order, Board columns and assignments, and prompt templates. Cove
stores that data in a separate versioned `workspace.json` restricted to the
current user and written through bounded, atomic replacement.

Unsaved composer text, prompts submitted to Codex, upstream titles, assistant
output, approvals, questions, commands, diffs, and transcripts remain
memory-only and are excluded from diagnostics, logs, notifications, fixtures,
and public artifacts. Privacy redaction also removes protected Workspace fields
from rendering, Accessibility, and search matching.

Thread control accepts only bounded start and exact-turn steer operations for a
validated composite identity. It rejects ambiguous origins, stale routes,
expected-turn changes, missing active turn IDs, and pending authoritative
requests. Local sockets remain private, remote relays retain strict SSH and
generation checks, and uncertain delivery is surfaced without automatic retry.

The protected distribution workflow will fail closed unless the reviewed tag
matches protected `main`, candidate evidence and tests pass, Developer ID
signing succeeds, Apple notarization and Gatekeeper checks succeed, and every
downloadable asset is covered by `SHA256SUMS`.

## Known boundaries

- The graphical app remains Apple Silicon only; Intel macOS support applies to
  the optional remote helper, not the app bundle.
- Workflow placement, aliases, tags, and links are Cove-only. This release does
  not store Jira, Confluence, Slack, GitHub, GitLab, Gerrit, Grafana, or other
  connector credentials.
- Freeform canvas layouts and saved custom-view builders remain deferred; Grid
  and Board are the two built-in Workspace views.
- Hook-only sessions and routes without an authoritative active turn remain
  read-only in Cove and use exact Open in Codex for native interaction.
- Homebrew availability follows the separate generated-Cask pull request; an
  immutable GitHub release alone does not update the tap's default branch.
