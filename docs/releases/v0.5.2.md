# Codex Cove 0.5.2
<!-- release-tag: v0.5.2 -->

Codex Cove 0.5.2 fixes remote helper setup on Linux hosts whose native Codex
installation uses the standard per-user binary location and restores visible
desktop transmission through the default collapsed island. These notes
describe the source candidate bound to `v0.5.2`; signing, notarization,
publication, and Homebrew availability remain prospective until the protected
release workflow finishes.

Source tag: `v0.5.2`

## Highlights

- Remote installation now recognizes a native Codex executable reached through
  the standard per-user binary path instead of misclassifying that location as
  a Cove-owned legacy shim.
- Cove continues to reject helper paths that resolve to its own managed binary,
  preventing recursive launches while leaving native Codex untouched.
- Remote deployment secures both the Cove support directory and its
  version-specific child to mode `0700` before installing the helper.
- Regression coverage exercises the default native Codex path and the complete
  remote deployment command contract.
- Thin, Regular, and Thick native materials now use a graduated translucent
  wash that keeps the configured theme tint while allowing the desktop behind
  the collapsed island to remain visibly transmitted.
- The controlled compositor regression test verifies the same collapsed island
  over light and dark backdrops and still honors macOS Reduce Transparency.

## Installation and compatibility

Codex Cove 0.5.2 is intended for Apple Silicon Macs running macOS 14 or newer.
Remote helpers support Apple Silicon and Intel macOS plus arm64 and x86_64
Linux-musl hosts. The release retains the `local.chris.codexcove` bundle
identity and upgrades an existing Homebrew installation in place while
preserving settings and custom themes. Codex CLI 0.145.0 or newer remains
required.

After the immutable release and generated Cask handoff are published and
merged, update with:

```sh
brew update
brew upgrade --cask cdimartino/codex-cove/codex-cove
```

The native `codex` command remains untouched. `codex-cove launch` remains the
explicit path for a broker-routed CLI session.

## Security and privacy

The remote and transparency fixes do not expand persistence, network scope, or
account access. Remote hosts remain opt-in SSH aliases with strict host-key
checking, helper checksums are verified before activation, and Cove-owned
support paths remain private to the current user. Privacy mode and macOS Reduce
Transparency continue to select an opaque fallback surface.

The protected distribution workflow will fail closed unless the reviewed tag
matches protected `main`, candidate evidence and tests pass, Developer ID
signing succeeds, Apple notarization and Gatekeeper checks succeed, and every
downloadable asset is covered by `SHA256SUMS`.

## Known boundaries

- The graphical app remains Apple Silicon only; Intel macOS support applies to
  the optional remote helper, not the app bundle.
- Remote tracking still requires explicit host configuration and a deployed
  helper; Cove does not scan SSH configuration or contact hosts automatically.
- Homebrew availability follows the separate generated-Cask pull request; an
  immutable GitHub release alone does not update the tap's default branch.
