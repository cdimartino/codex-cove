# Codex Cove 0.4.0
<!-- release-tag: v0.4.0 -->

Codex Cove 0.4.0 adds complete custom-theme authoring, selectable resident
families, and a native Codex-by-default installation. These notes describe the
source candidate bound to `v0.4.0`; signing, notarization, publication, and
Homebrew availability remain prospective until the protected release workflow
finishes.

Source tag: `v0.4.0`

## Highlights

- Settings exposes native color-wheel pickers for the major island, queue,
  status, resident, border, and text colors, plus opacity and blur controls.
- Custom themes can be named, saved locally, selected later, and exported as
  portable JSON without including task or account data.
- Residents can use one of three distinct visual families: Dungeon/D&D, Tech
  Creatures, or Virus/Bacteria. The selected family and stable task assignment
  persist between launches.
- Opening Settings immediately collapses the island and keeps it collapsed
  until the Settings window closes.
- Fresh installs no longer replace the native `codex` command with a Cove shim.
  Native Codex and hooks are the default; `codex-cove launch` remains available
  when an explicitly broker-routed session is wanted.
- Upgrades remove only a legacy `codex` link that an earlier Cove install
  recorded as owned. Foreign commands and links are preserved.

## Installation and compatibility

Codex Cove 0.4.0 is intended for Apple Silicon Macs running macOS 14 or newer.
It retains the `local.chris.codexcove` bundle identity and upgrades an existing
Homebrew installation in place while preserving settings and custom themes.

After the immutable release and generated Cask handoff are published and
merged, update with:

```sh
brew update
brew upgrade --cask cdimartino/codex-cove/codex-cove
```

Run `codex` normally for the native client. Use `codex-cove launch` only for an
explicitly Cove-routed CLI session. Terminal.app, iTerm2, tmux, WezTerm, VS
Code, Cursor, selected SSH hosts, and Codex Desktop exact-origin navigation
remain supported.

## Security and privacy

Theme and resident preferences remain local. Exported theme JSON contains only
the theme name, colors, opacity, and blur values. It never includes prompts,
responses, commands, diffs, task identifiers, account data, or paths.

The protected distribution workflow will fail closed unless the reviewed tag
matches protected `main`, candidate evidence and tests pass, Developer ID
signing succeeds, Apple notarization and Gatekeeper checks succeed, and every
downloadable asset is covered by `SHA256SUMS`.

after the workflow re-downloads and verifies the immutable release bytes.

## Known boundaries

- The graphical app remains Apple Silicon only; Intel macOS support applies to
  the optional remote helper, not the app bundle.
- Theme import remains file-based; Cove does not sync custom themes.
- Resident selection changes the character family, not task state or routing.
- Hook-only native Codex sessions keep approvals and questions in Codex; use
  `codex-cove launch` when Cove handling is specifically desired.
- Homebrew availability follows the separate generated-Cask pull request; an
  immutable GitHub release alone does not update the tap's default branch.
