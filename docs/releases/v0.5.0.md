# Codex Cove 0.5.0
<!-- release-tag: v0.5.0 -->

Codex Cove 0.5.0 makes theme editing visible immediately, restores reachable
idle-hide behavior, uses native macOS translucency, and shows useful task
output in the expanded queue. These notes describe the source candidate bound
to `v0.5.0`; signing, notarization, publication, and Homebrew availability
remain prospective until the protected release workflow finishes.

Source tag: `v0.5.0`

## Highlights

- Custom themes can use either a solid surface or a two-color gradient. Native
  color-wheel changes preview immediately on the installed island before save.
- Collapsed and expanded surfaces apply their configured tint opacity over a
  native macOS backdrop blur. Privacy mode and Reduce Transparency still force
  an opaque surface.
- Idle auto-hide now collapses to a clickable menu-bar-level cue. The cue,
  menu-bar command, or global visibility shortcut restores the full island.
- Expanded task cards show the latest assistant output when Codex exposes it,
  with the complete output available in focused detail instead of a generic
  hook or tool-event label.
- Saved and exported custom themes preserve the selected solid or gradient
  fill. Existing theme documents remain compatible and default to gradient.

## Installation and compatibility

Codex Cove 0.5.0 is intended for Apple Silicon Macs running macOS 14 or newer.
It retains the `local.chris.codexcove` bundle identity and upgrades an existing
Homebrew installation in place while preserving settings and custom themes.
Codex CLI 0.145.0 or newer remains required.

After the immutable release and generated Cask handoff are published and
merged, update with:

```sh
brew update
brew upgrade --cask cdimartino/codex-cove/codex-cove
```

The native `codex` command remains untouched. `codex-cove launch` remains the
explicit path for a broker-routed CLI session.

## Security and privacy

Latest assistant output is transient in-memory content. It is not written to
Cove's session metadata, diagnostics, or exported themes, and Privacy mode
redacts it from Cove surfaces.

Theme exports contain only the theme name, colors, fill mode, opacity, blur,
and other visual settings. They do not include task, account, path, prompt,
response, command, or diff data.

The protected distribution workflow will fail closed unless the reviewed tag
matches protected `main`, candidate evidence and tests pass, Developer ID
signing succeeds, Apple notarization and Gatekeeper checks succeed, and every
downloadable asset is covered by `SHA256SUMS`.

## Known boundaries

- The graphical app remains Apple Silicon only; Intel macOS support applies to
  the optional remote helper, not the app bundle.
- Latest output depends on a bounded public app-server enrichment request. If
  that request is unavailable, task metadata and **Open in Codex** still work.
- Theme import and export remain file-based; Cove does not sync custom themes.
- Homebrew availability follows the separate generated-Cask pull request; an
  immutable GitHub release alone does not update the tap's default branch.
