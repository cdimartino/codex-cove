# Codex Cove 0.9.0
<!-- release-tag: v0.9.0 -->

Codex Cove 0.9.0 brings live agent activity into the Workspace dashboard.
Parent task cards now show bounded output excerpts from the newest related
agent as public app-server deltas arrive, and the task's assigned resident can
appear and animate directly on Grid and Board cards. These notes describe the
source candidate bound to `v0.9.0`; signing, notarization, publication, and
Homebrew availability remain prospective until the protected release workflow
finishes.

Source tag: `v0.9.0`

## Highlights

- Workspace cards update from `item/agentMessage/delta` events while an agent
  is responding, without waiting for the final message.
- A parent card selects the newest output across that task and its attached
  descendants, labels the excerpt with the producing task or agent, and keeps
  unrelated origins isolated.
- Starting a new assistant message clears the previous excerpt. A completed
  message replaces streamed text with the authoritative final output.
- Grid and Board cards reuse Cove's stable per-task resident assignment and
  existing native pixel renderer.
- **Settings → Residents** can hide residents on Workspace cards or pause
  active-state movement independently. macOS Reduce Motion remains
  authoritative.
- Card output is included in the card's Accessibility value while resident
  artwork remains decorative, avoiding duplicate announcements.

## Installation and compatibility

Codex Cove 0.9.0 is intended for Apple Silicon Macs running macOS 14 or newer.
Remote helpers support Apple Silicon and Intel macOS plus arm64 and x86_64
Linux-musl hosts. Codex CLI 0.147.0 or newer remains required for Workspace
thread discovery and control.

This feature release keeps Workspace schema version 3, the
`local.chris.codexcove` bundle identity, and existing settings and session
formats. The two new resident preferences decode to enabled for existing
installations, so upgraded users see their assigned resident and active
movement unless they turn either option off.

After the immutable release and generated Cask handoff are published and
merged, update with:

```sh
brew update
brew upgrade --cask cdimartino/codex-cove/codex-cove
```

The native `codex` command remains untouched. `codex-cove launch` remains the
preferred path for continuously broker-routed CLI sessions.

## Security and privacy

Streaming output is held only in the existing transient session snapshot. Cove
retains at most 4,000 characters per active session and renders at most the
trailing 360 normalized characters on a card. It does not persist those
excerpts to Workspace JSON, SQLite metadata, diagnostics, logs, notifications,
or release evidence.

Privacy redaction removes output text, its producer label, and resident artwork
from both rendering and Accessibility. Output projection uses the existing
composite source, remote-host, and opaque session identity, so two tasks with
the same raw session ID cannot share output across origins. This release adds
no network request, telemetry, connector credential, hosted service, or new
dependency.

The protected distribution workflow will fail closed unless the reviewed tag
matches protected `main`, candidate evidence and tests pass, Developer ID
signing succeeds, Apple notarization and Gatekeeper checks succeed, and every
downloadable asset is covered by `SHA256SUMS`.

## Known boundaries

- Real-time card updates require public app-server agent-message delta events.
  Hook-only tasks without that stream continue to update when Cove receives a
  bounded final assistant message.
- Cards intentionally show a compact trailing excerpt, not a transcript or
  Markdown document. Open the exact task in Codex for full output and context.
- A parent card displays only the newest related output at a time. The
  inspector hierarchy remains the authoritative view of all attached agents.
- Resident movement is status-driven and decorative. Status text and symbols
  continue to carry the semantic state when animation is paused or unavailable.
- Homebrew availability follows a separate generated-Cask pull request; an
  immutable GitHub release alone does not update the tap's default branch.
