## 0.2.0 implementation

- Deterministic, fail-closed XCUITest fixture host with isolated storage,
  disabled external effects, and injected-sender invocation counting.
- Semantic typography and contrast enforcement across all built-in themes.
- Select-then-confirm approval scopes, single-flight delivery, failure/retry,
  dirty-draft protection, keyboard-path coverage, stable AX identifiers and
  labels, and explicit status copy. Full Keyboard Access and VoiceOver
  completion remain manual release checks.
- Three-state overlay: collapsed, attention-first queue, and focused action.
- One queue scroll owner, grouped/deduplicated attention work, anchored sizing,
  visible row actions, and focused Escape behavior.
- Precision timing controls, project-token editing, the 6-by-6 notification
  policy matrix, compact sound disclosures, and corrected resident wording.
- Shared Xcode UI-test project/scheme while SwiftPM remains the production
  build source.
- macOS 26-compatible installer process detection and reliable four-target
  remote-helper builds when Homebrew and rustup Rust coexist.
- Composite task origin throughout reduction, persistence, decisions,
  notifications, and jumps: local CLI and Desktop are scoped by source, while
  remote CLI also requires its selected host ID. Missing or ambiguous origin
  fails closed instead of falling back to whichever task is current.
- A documented schema-v1 presentation limitation: cards are still keyed by a
  raw upstream ID, so a cross-origin snapshot/session/launch collision hides
  the colliding incoming card rather than merging or misrouting it. Supporting
  two simultaneously visible cards with the same raw ID requires a later
  schema/presentation identity change.
- VS Code/Cursor routing is per editor window and per terminal. A Cove-created
  routed terminal gets a fresh opaque `cove-editor-<UUID>` launch ID; live
  registrations can bind before or after launch and retain historical session
  membership for sequential tasks in that terminal. The extension clears
  legacy sensitive global state and persists only a validated opaque extension
  session ID, never cwd, shell, terminal name, prompt, response, command, diff,
  or marker content. Exact Open uses a content-free, per-window accessibility
  anchor derived from the ephemeral focus-socket identifier. It confirms the
  terminal selection, raises and verifies exactly one matching native editor
  window, then confirms terminal and window focus again. Missing permission,
  zero or multiple anchors, an unselected terminal, or a window-focus mismatch
  fails closed.
- Remote decision controls carry a unique `controlId`; the remote helper sends
  a correlated internal `decisionAck` only after its private decision-socket
  write succeeds or fails. Per-host writes are serialized, failures/timeouts
  keep the route retryable, and disconnect fails pending sends and invalidates
  that relay generation's routes. This is not a downstream Codex
  acknowledgment.
- A bounded, launch-scoped, memory-only startup notification buffer preserves
  qualifying attention while Notification Center initializes, then drains in
  FIFO order only after rechecking current attention and privacy/suppression
  settings. Notification opens resolve the exact persisted source/host plus
  session and launch, and ambiguity fails closed without a current-task
  fallback.
- The collapsed island is a real accessible Button named `Open task queue`
  with a stable AX identifier, value, and hint. Privacy controls expose stable
  AX identifiers, and live project/task suggestions disappear from both the
  Settings UI and accessibility tree while privacy redaction is active.
- Doctor validates the private manifest, owned paths and hashes, installed app
  bundle identity/version, the freshly recomputed app tree hash, exact hook
  ownership, exact recorded editor targets, live socket safety, schemas, and
  optional remote artifacts.
- Install and uninstall mutation paths preserve a valid existing helper
  configuration, serialize writers under the persistent instance/config lock,
  bind preflight/staging/commit/rollback to current-user filesystem identities,
  and fail closed on identity drift. Editor cleanup obligations are recorded by
  target; uninstall is reversible until commit and reports cleanup failures
  instead of claiming success.

Remote removal now has a tested recovery path: normal removal contacts the
selected host first and preserves local configuration on failure;
`remote remove ALIAS --forget` is strict local-only cleanup and cannot invoke
SSH. It does not prove or perform remote cleanup. Cove must be quit for add,
remove, or forget; the helper shares its instance lock and refuses before SSH
or config mutation while the app is running, so no stale relay can survive a
reported cleanup.

For a local CLI decision, production success means the complete frame was
written to the validated private socket; there is no receiver ACK. For a
remote CLI decision, Cove waits for the relay's correlated internal
`decisionAck`, which confirms only that the remote helper completed its private
socket write. Neither path proves that downstream Codex accepted or completed
the decision.
